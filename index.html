Privacy Policy

This game does not ask users to provide personal information (such as name, address, or phone number). However, the game uses third-party services (such as Firebase and Google AdMob), which may collect certain data as described in their respective policies.

Progress & Gameplay Data

To provide core features and improve the game, we may store gameplay progress, such as the current level, completed levels, and basic in-game events. This data is used to save progress across sessions and to help improve game balance and difficulty.

Firebase (Google)

This game uses Firebase to store gameplay progress and deliver game content. Depending on the Firebase services enabled, Firebase may collect technical information such as device identifiers, app usage data, and diagnostics (for example, crash and performance data).

Advertising

This game uses Google AdMob to display ads. AdMob may collect device and usage information to show ads and measure ad performance.

In-App Purchases

The game offers optional in-app purchases. All payments are handled securely by the app stores.
